从 v2.0.3 到这个版本，一共攒了几轮实打实的改动。挑值得说的：

## 登录
- **微信扫码登录打通**：本地生成 ECDH P-256 密钥对 → 授权码换令牌 → HKDF-SHA256 派生密钥 → AES-GCM 解密服务端响应。桌面浏览器打不开那个链接，所以流程是：扫码 → 微信里点「⋯ → 复制链接」→ 回来点「从剪贴板读取并登录」。
- 账号密码 / 用户ID+图形验证码 两条备用登录路径。

## 答题正确率
- **接在线词典 + 本地词库**：答题从「凭记忆」变成「查得到」。有道 `dict.youdao.com/jsonapi` → 释义单元匹配选项，阈值 0.60 + 0.15 领先幅度，拿不准就交给下一环。可选离线 `ecdict.json`，结果缓存进 `glossary.json`。
- 权威释义直接注入大模型提示词，让它做「选」，不做「想」。
- 策略链：题库 → 规则 → 词库 → 大模型 → 试答案 → 盲选，每一环都能报出命中数。

## 班级任务（只有一次机会）
- 默认**关掉**「试答案」：故意答错会永久留在成绩里。
- 开跑前自动「备题」：按 `list_id` 找到对应的自学任务先刷几轮把题库喂饱，再进班级任务。
- 题库覆盖率低于 60% 会在日志里提醒。

## 令牌有效期
- 实测令牌**约 6 小时**过期（10:16 登录 → 16:22 开始回 `11003 需安全验证`）。
- 登录后记录时间戳，快到点在界面和日志里提醒；`11003` 会直接给出四步处置说明。

## 修掉的一个真 bug（本版重点）
登录成功后 `write_token` 把「令牌获取时间」写进 `config.json`，紧接着设置令牌输入框触发自动保存，把内存里那份启动时载入的旧副本整体写回磁盘 —— **时间戳当场被清空**，6 小时提醒从此不响，用户只能撞上 11003。

修法：落盘前和磁盘上的值比一次，谁新用谁；登录成功时同步内存副本。附 4 个回归用例，外加一个对着真配置复现的验证脚本。

## 顺手的清理
- `unittest discover` 之前跑不起来（缺 `tests/__init__.py`），已补。
- `vocabgo/__init__.py` 的 docstring 不知何时被 GBK 误读成了乱码，已修回。
- 新增 `tools/mk_working_copy.py`：`build_release.py` 每次都会清空目标目录，这个脚本负责把上一份活的配置/题库搬回来。
- 新增 `tools/snap_window.py`：抓主窗 + 模态对话框的截图工具。

## 安装
1. 下载下面的 `vocabgo-auto-v2.1.4-win64.zip` 解压
2. 双击 `Vocabgo.exe`（首次运行若提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」）
3. 「设置」页 → 「⭐ 一键填入推荐配置」→ 粘贴 DeepSeek 密钥 → 保存
4. 「刷题」页 → 「登录获取令牌」→ 微信扫码 → 复制链接 → 「从剪贴板读取并登录」
5. 「刷新任务」→ 选任务 → 「▶ 开始刷题」

详见包内 `说明书.html`（图片已内嵌，无需联网）与 `快速上手.txt`。

## 说明
- **zip 里不含任何密钥、令牌或个人配置**，打包脚本会逐字节扫描，扫到就中止。
- 程序运行时会在自己所在目录生成 `config.json`（明文存密钥和令牌），别把整个文件夹直接分享出去。
- 测试：165 个用例全部通过。
