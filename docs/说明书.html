1. 这是什么

一个把「词达人」里重复的单词练习自动做完的小工具。你只需要在第一次使用时做两件事：填一个大模型密钥、用微信扫一下码。之后每次打开就能直接开刷。

它能做什么

  • 自动完成班级任务与自学任务，覆盖全部题型（单词记忆、词义选择、句中选义、短语排序、搭配多选）
  • 自动选满所有词、自动签到、按阈值重练未满分的词直到刷满
  • 答完的题会进本地题库，越用越快（同一道题第二次直接命中）
  • 题干/选项意外变成图片时，自动调用大模型或本地识别把文字读出来
  • 日志实时可见，命中来源一目了然（题库 / 规则 / 试答案 / 大模型）

它不做什么

  • 不破解、不绕开平台鉴权 —— 用的是你本人账号的正常接口，和网页版点按钮等价
  • 不帮你登录 —— 令牌必须由你本人产生（账号密码登录，或自己抓自己的包）
  • 不保证 100% 不被平台发现（见第 8 章「稳定性与注意事项」）
使用前请知悉 自动化操作属于平台规则里的灰色地带，平台随时可能调整接口或加强风控。请用自己的账号、按第 8 章的节奏使用，不要一次刷爆、不要多人共用同一个账号。

2. 3 分钟上手

  1. 解压并打开
    把压缩包解压到任意文件夹（不要放在 C 盘系统目录里），双击 Vocabgo.exe。首次启动 Windows 可能弹「已保护你的电脑」，点「更多信息」→「仍要运行」。
  2. 填大模型密钥（只要一个 key）
    切到「设置」页 → 点「⭐ 一键填入推荐配置」（地址、模型名会自动带好）→ 在「接口密钥」里粘贴你的 DeepSeek 密钥 → 点右边的「💾 保存配置」。
    密钥在 platform.deepseek.com 注册后创建，几块钱能用很久。
  3. 登录获取令牌
    回到「刷题」页 → 点「登录获取令牌」→ 填你的词达人用户名 / 学号 + 密码 → 点「登录」→ 令牌自动填好并写进配置。
  4. 选任务，开刷
    点「刷新任务」→ 在列表里点一下要刷的那条 → 点「▶ 开始刷题」。剩下的交给它，日志区会一行行告诉你进展。
下次使用 直接双击 Vocabgo.exe，点「刷新任务」→「开始刷题」即可。密钥、地址、模型、节奏、上次刷的任务都会自动带出来。

3. 推荐配置

程序里点「⭐ 一键填入推荐配置」就是下面这套值。它针对「稳定拿高分、又不显得像机器」这一目标调的：

项目推荐值为什么这么设
服务商DeepSeek答题兜底 + 读图一把 key 搞定，价格低
答题模型deepseek-v4-flash从选项里挑答案这种短任务，够用、快、便宜
读图模型deepseek-flash支持图片输入，题干万一变成图片也能认出来
思考模式关闭每题都推理会又慢又贵，短答提取不需要
作答间隔1.5 ~ 3.5 秒比默认再慢一点，更像人在做题，降低被风控关注
试答案兜底开启生词也能先判对再提交，分数不会掉
读图开启（自动）有模型时用模型，没有就退回本地识别，不影响流程
练习轮数3自动重练没满分的词，把分追满
满分阈值1010 分制下的满分线

程序目录里另外附了一份 config.推荐.json，内容与上面一致。如果你想手动替换配置，把它改名为 config.json 覆盖即可（记得重新填密钥和令牌）。

只填密钥也能跑 其他项都有默认值：万一你没配大模型，程序会自动退回「本地题库 + 规则匹配 + 试答案」链路，仍然能做完；只是遇到生词时准确率不如接了大模型。

4. 详细教程

4.1 安装与启动

免安装版（推荐）：解压后双击 Vocabgo.exe。整个文件夹可以放在桌面或 D 盘任意位置，也可以拷到 U 盘带走。

源码运行（进阶）：需要 Python 3.10+，在项目目录执行：

pip install -r requirements.txt
python vocabgo_app.py

4.2 获取用户令牌

令牌（usertoken）是程序代表你操作账号的凭据，必须由你本人产生。三种方式，优先用第一种：

方式 A：账号密码登录（推荐）

  1. 点主界面的「登录获取令牌」
  2. 在「方式一」里填你的词达人用户名 / 学号与密码，点「登录」
  3. 成功后令牌会自动写入配置，界面上的「用户令牌」也会填好
没有密码怎么办 先用微信在词达人官网／公众号登录，进去后在个人设置里设置一个密码；也可以直接用下面的方式 C 抓包。

方式 B：用户ID + 图形验证码

如果你手上只有「用户ID」（不是用户名），用登录对话框里的「方式二」：

  1. 点「换一张」——验证码图片会直接显示在对话框里
  2. 照着图填「用户ID / 密码 / 验证码」，点「登录」

命令行等价用法：

python -m vocabgo captcha                      # 取一张验证码，存成 验证码.png（同时打印 req_no）
python -m vocabgo login --id 你的ID --password 你的密码 --valid-code 图上的字符 --req-no 上一步的req_no

方式 C：抓包（最稳，任何登录方式失效时都能用）

pip install mitmproxy
mitmdump -s tools/mitm_capture.py

然后让电脑上的微信走 127.0.0.1:8080 代理，打开「词达人」公众号 → 学生端，随便点进一个任务页面。插件会自动把三个字段写进配置文件：

字段是什么
usertoken用户令牌，代表你账号的凭据。必须由你本人产生
abc平台的一道反爬校验，值 = md5(客户端 User-Agent)。留空即可，程序会自己算
authorization-v同类的版本标记，值是固定的 md5("0")。留空即可

界面上的「abc 字段」「authorization-v 字段」就是后两个。它们留空也能跑：程序按当前 UA 自动推算，抓包填了真值则优先用真值。

关于曾经的「扫码授权」 早期版本提供过微信扫码授权，现在已不可用：那条链路走的是第三方授权接口，实测扫码后服务端会返回「微信认证失败」（新版客户端登录已改成握手 + 公钥加密传输）。 现在请用上面的账号密码登录，或抓包。主界面上的「扫码授权」按钮已被「登录获取令牌」取代。
所以：不抓包也能用 账号密码登录只需要用户名和密码，另两个鉴权字段由程序推算。只有登录方式全部失效时，才需要抓包兜底。
令牌会失效 使用时不要在手机或其它设备上登录词达人，一旦在别处登录，令牌会被刷新失效。真失效了重新登录即可。界面上点「测试连接」可以随时确认令牌是否有效。

4.3 配置大模型

  1. 「设置」页 → 点「⭐ 一键填入推荐配置」→ 接口地址与两个模型名自动带出
  2. 在「接口密钥」里粘贴密钥 → 点「💾 保存配置」
  3. 鼠标点走或按回车时，程序会自动拉取模型列表；也可以点「拉取模型列表」手动拉。拉回来后自动帮你选好「答题模型」和「读图模型」，两个框都能下拉改选
  4. 点「大模型体检」验证：出现下面三行就说明配好了 
    📋 可用模型 3 个：deepseek-v4-flash, deepseek-v4-pro, deepseek-flash
💬 对话测试：✅ 模型回了 'OK'
🖼️ 读图测试：✅ 识别为 'abandon'
密钥存在哪？安全吗？ 存在程序目录的 config.json 里，明文。别把这个文件发到群里，也别把整个文件夹连密钥一起分享给别人 —— 发之前先把密钥删掉。

4.4 选任务并开始刷题

切到「刷题」页：

刷题页：上半部分是账号与任务，下半部分是实时日志

  1. 选择任务类型：班级任务（老师布置的）或 自学任务（自己练的，需要填课程代码，默认 CET4_v2）
  2. 点「刷新任务」，下面的列表会列出你可做的任务（名称 / 进度 / 得分 / 编号）
  3. 点一下要刷的那条（下次打开会自动选回上次那条）
  4. 点「▶ 开始刷题」

4.5 看日志：每道题是怎么答对的

日志里每行末尾的方括号就是这道题的命中来源：

标记含义风险
[题库]以前答过，直接命中本地题库最低
[规则]用「单词记忆」题学到的词义表直接选中正确释义很低
[试答案]先故意答错，从服务端返回里套出正确答案，再用正确答案重判一次中（会留下错误作答轨迹）
[大模型]交给 DeepSeek 判断很低
[猜测]实在没辙盲选（正常应该看不到）高

一趟刷完会打印统计，例如：

🎉 结束：120/120　进度 120/120 | 题库 96 | 规则 18 | 试答案 6 | LLM 0 | 猜测 0 | 服务端纠错 0

「题库」越大、「试答案」越小，说明你账号上的作答轨迹越干净。想更干净：配好大模型后，取消勾选「试答案兜底」。

4.6 把分追满

  • 「练习轮数」设 3：刷完一轮后自动重开一轮，只练没到满分的词
  • 「满分阈值」设 10：10 分制的满分线；想更快结束可调到 9
  • 中途想停就点「⏹ 停止」，会在当前这题收尾后停下，题库照常保存

4.7 换账号 / 换电脑 / 备份

  • 换账号：清空「用户令牌」→ 点「登录获取令牌」用另一个账号登录
  • 换电脑：把整个文件夹拷过去即可，配置和题库都在里面
  • 备份题库：复制 bank.json；它是纯文本，可以用记事本看
  • 多账号：每个账号复制一份完整文件夹，互不干扰

6. 它是怎么答对题的

每道题按下面的顺序尝试，命中就停：

读图 → 题库 → 规则匹配 → 试答案 → 大模型 → 盲选
环节做什么
读图题干/选项以图片下发时，先识别成文字（题目正常情况下是纯文本，这一步一般用不到）
题库题目指纹命中本地缓存，直接给出上次的正确答案
规则匹配「单词记忆」题型本身会给出单词的全部释义，程序顺手记下，后面的选择题直接查表；搭配题里服务端把答案词放在备注里，也能直接取
试答案连续提交两次错误答案后，服务端会回吐本题正确答案；拿到后再用正确答案重新判一次，所以最终记录的仍是正确作答
大模型把题干和选项交给模型判断（一词多义、短语排序这类题最有用）

答过的题会写回 bank.json，所以同一套词练第二遍几乎全是「题库」命中，又快又干净。

7. 常见问题

Q1：提示「用户令牌已失效」

最常见的原因是你在手机或别的电脑上登录了词达人，令牌被刷新了。重新点「登录获取令牌」即可。

Q2：登录提示「用户名错误」或「密码错误」

用户名/密码不对。注意：「用户名」通常是注册时的手机号或学号，不是昵称。忘了密码就先用微信在官网登录，进去后在个人设置里改一个密码；或者直接改用抓包方式。

Q3：报「余额不足 / 401 / 无效的 API key」

密钥不对或余额用完了。到服务商控制台检查密钥、充值，然后点「大模型体检」复验。

Q4：拉不到模型列表

不影响使用 —— 只是该服务商没提供模型列表接口。手动把模型名填进「答题模型」即可（DeepSeek 填 deepseek-v4-flash）。

Q5：分数没满

把「练习轮数」调到 3~5、「满分阈值」保持 10，程序会自动重练未满分的词。

Q6：日志出现「试答案纠正失败，按现状提交」

极少数题型服务端不给答案。这一题会被记为错，下一轮重练会再试一次。如果频繁出现，把日志整段发给作者。

Q7：界面提示「没查到任务」

可能原因：令牌失效；老师还没发布任务；任务已全部完成（把「任务筛选」理解为「全部」）。

Q8：自学任务报错

自学任务第一次选词偶发报错是平台侧的老现象，再点一次「开始刷题」通常就好。

Q9：换电脑后要重新配吗

不用。把整个文件夹拷过去，配置与题库都在里面。只有令牌可能因为异地登录失效，重新登录即可。

Q10：会被封号吗

见下一章。简单说：按推荐节奏、别多设备乱登录、别一口气刷完整个自学任务，风险可控但不为零。

Q11：界面上的「abc 字段」到底是啥

平台的接口校验字段，值 = md5(你的客户端 User-Agent)；旁边的 authorization-v 是同类标记，值固定为 md5("0")。两个都可以留空 —— 程序会自己推算。抓包填了真值就优先用真值。

Q12：日志里出现 ProxyError / JSONDecodeError / 「目标计算机积极拒绝」

这是电脑上的代理在作怪，不是软件坏了。很多人的机器上装过 Clash / V2Ray，系统里留着代理设置（常见的是 127.0.0.1:7890）。代理程序一关，所有联网请求就会失败。

本程序默认直连（会主动忽略系统代理），所以正常情况下不受影响。如果还是报这类错：

  1. 到「设置」页看「代理」那一行：确认留空、且没有勾选「跟随系统代理」
  2. 确实需要走代理（比如校园网限制），才在那一行填代理地址，例如 http://127.0.0.1:7890
  3. 拿不准就把代理程序打开再试，或临时关掉系统代理

Q13：提示「连不上服务器 / 请求超时」

先确认网络本身正常（浏览器能打开网页）。如果开了 VPN / 加速器，关掉再试 —— 词达人是国内服务，走代理反而更慢更不稳。

Q14：为什么没有「扫码授权」了

早期版本用微信扫码授权，那条链路走的是第三方授权接口，平台已经改了：实测扫码后服务端返回「微信认证失败」（新版客户端登录改成握手 + 公钥加密传输）。所以现在改成账号密码登录，接口更简单也更稳。实在登录不了就用抓包。

Q15：日志里出现 code=11003 需安全验证

表示这次请求没有带上有效的用户令牌（要么没登录、要么令牌已失效）。重新「登录获取令牌」或点「测试连接」确认。

8. 稳定性与注意事项

事项建议
作答节奏保持 1.5 ~ 3.5 秒。别为了快而改成 0（界面里没有这个选项，改配置文件也别设 0）
多设备登录刷题期间不要在手机/其它电脑登录词达人，令牌会被挤掉
刷题量不要一次性刷完整个自学任务，分几次、隔一段时间更稳妥
试答案会让服务端看到「错两次再对」的轨迹。题库越大它越少；配好大模型后可关掉
运行环境用正常电脑/微信客户端。模拟器、Xposed 之类的环境风险明显更高
接口变更平台改接口时工具会失效。表现为报错或大批量「猜测」，此时先看程序目录有没有新版本
密钥保管config.json 里有明文密钥，别直接分享整个文件夹

9. 文件位置与卸载

所有数据都在程序目录，不写注册表、不装服务：

文件 / 目录说明
Vocabgo.exe主程序，双击运行
_internal\运行库，不要删也不要单独移动
config.json你的全部配置（令牌、密钥、节奏）
bank.json本地题库，越用越大，可随时删（删了不影响使用，只是重新积累）
验证码.png用命令行取图形验证码时生成的临时图片，可删
说明书.html就是本文档
selftest.txt环境自检报告，排查问题时有用

卸载：直接删除整个文件夹即可，没有残留。想保留题库就先把 bank.json 复制出来。

附录 B：命令行用法（进阶）

发布包里另有一个命令行版本 VocabgoCLI.exe（需要单独下载或从源码运行 python -m vocabgo）：

python -m vocabgo config --recommend      # 写入推荐配置
python -m vocabgo check                   # 检查令牌
python -m vocabgo tasks --kind class      # 列出班级任务
python -m vocabgo run --kind class --index 0 --loop 3
python -m vocabgo llm --image             # 大模型体检（含读图测试）
python -m vocabgo vision --test           # 读图能力体检
python -m vocabgo run --kind study --course CET4_v2 --index 0

常用开关：--fast（去掉等待，仅供调试）、--no-probe（关掉试答案）、 --no-ocr（关掉读图）、--debug（打印每次请求与响应）、--bank 路径（指定题库文件）。
